## Default Permission

Default permissions for the TimeManage Android timer notification plugin.

#### This default permission set includes the following:

- `allow-start`
- `allow-update`
- `allow-stop`
- `allow-finished`
- `allow-requestPermission`
- `allow-registerListener`
- `allow-removeListener`
